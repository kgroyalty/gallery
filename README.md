# gallery

Public image assets for Royal Empire Notion pages. Notion only accepts page covers from a public URL, so the images live here.

- `skills/<skill>-cover-v<semver>.png`: Skills Library page covers, 1500x500, no text. Source SVGs and the generator (`notion_cover.py`) live in the private Royal-Empire-Ecosystem repo under `platform/armory`.

Nothing private belongs in this repo. Images only.
